# NexColetas — Diretório Oficial de Assets da Marca

Esta pasta está preparada para armazenar os arquivos individuais transparentes (PNG/SVG) da identidade visual oficial **NexColetas — Logística de Coletas Urbanas**:

1. `logo-horizontal.png` — Logo principal horizontal
2. `logo-symbol.png` — Logo reduzida / símbolo (N 3D com seta e caixa isométrica)
3. `logo-light-bg.png` — Logo para aplicação em fundo claro (`#F1FDF4` / `#FFFFFF`)
4. `logo-dark-bg.png` — Logo para aplicação em fundo escuro (`#0B2E1E` / `#111827`)

Enquanto os arquivos PNG recortados individualmente não forem depositados nesta pasta, o componente `<NexColetasLogo />` (`src/components/brand/NexColetasLogo.tsx`) renderiza vetorialmente o símbolo e o logotipo oficial respeitando rigorosamente as proporções, tipografia (`Montserrat ExtraBold Italic`) e paleta (`#0B2E1E`, `#166534`, `#22C55E`, `#84CC16`, `#F1FDF4`, `#111827`) do manual de referência em `/public/assets/aistudio/69e5455b69f2773f2feb888acaf03d0ba7fdfde9fb495075fc0910b9f982769f_68eabbc8.png`.
